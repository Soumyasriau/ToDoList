# Todo List App

A full-stack todo app with a dashboard: tasks with due dates and priorities, a calendar, progress stats, and a daily quote.

**Live demo:** https://todolist-web-6j81.onrender.com

Note: the server runs on a free plan, so the first request can take 30 to 60 seconds to wake up.

## Features
- Add, edit, complete and delete tasks
- Due dates with overdue and due-today counters
- Priority levels (high, medium, low)
- Calendar and progress bar
- Filters: All, Active, Completed
- Daily motivational quote

## Tech stack
- Client: React
- Server: Node.js, Express
- Database: MongoDB Atlas
- Hosting: Render

## Run locally
1. Clone the repo.
2. Server: cd Server, create a .env file with MONGO_URI=your_connection_string, then run npm install and node server.js.
3. Client: cd Client, run npm install and npm start.
